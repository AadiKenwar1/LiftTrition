New graph language

Built on the Refined system already in the app — crisp cards, restrained glow, sentence-case. Four real upgrades: a clean press read-out instead of stacked glow rings, an end-of-line value flag, bars for Sets (counts, not a smoothed line), a goal reference line for body weight — and a stat row that drops the uppercase bordered chips. Lift blue / Nutrition green as always.

1
Press read-out pill
Tap-and-hold shows a single value + date pill with a thin guideline — replacing the four stacked translucent circles.
2
End value flag
The latest value is always labelled at the end of the line, so the headline number is readable at a glance.
3
Quiet stat row
Inset row with sentence-case labels and a colored trend arrow — no more uppercase bordered boxes.
4
Lighter axes
Four hairline gridlines in the ring-track grey, sentence-case date ticks, no chart border noise.
